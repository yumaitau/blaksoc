## How to add a decision

Copy this block. Number decisions in order and never reuse a number. To change a decision, add a new one
that supersedes it rather than editing the old one.

```markdown
### CD-000: <short title>

- **Date decided:**
- **Session or channel:** (for example, discovery session 2, or written review)
- **Question:**
- **Decision:**
- **Why:** (de-identified; no names without consent)
- **Implements:** #<issue>, #<issue>
- **Supersedes:** (if any)
- **Read back to the group on:**
- **Status:** agreed | built | not built (reason)
```
